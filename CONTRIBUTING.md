# Contributing

Thank you for helping make Chilon Recall more useful for learners and knowledge workers.

1. Open an issue before large architectural changes.
2. Keep credentials, private documents, generated indexes, and personal paths out of commits.
3. Add or update tests for behavior changes.
4. Run `npm run check` and `npm audit --audit-level=high` before opening a pull request.
5. Explain user impact, compatibility, validation, and any data-safety implications in the pull request.

Use synthetic or clearly redistributable fixtures. Do not contribute copyrighted textbooks or private workplace material.
